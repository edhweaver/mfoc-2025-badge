# mfoc-2025-badge

This repo contains the Design Files and supporting documentation for the Maker Faire Orange County 2025 Badge.
* maker-faire-badge.kicad_pro - KiCad Project File
* maker-faire-badge.kicad_prb - KiCad Layout File
* maker-faire-badge.kicad_sch - KiCad Schematic File
* Library.pretty\ - contains all footprints artwork
* Manufacturing Files
  * PCB-maker-faire-badge-Rev_X.zip - Printed Circuit Board Artwork and Fabrication Files
  * ASSEMBLY-maker-faire-badge-Rev_X.zip - PCB Assembly Files (Bill of Materials and Assembly Documentation)
* README.mk - this file
* CHANGES.txt - Change log of modifications from prior published design as required by the CERN-OHL-S license
* cern_ohl_s_v2_user_guide.txt - User Guide for the CERN-OHL-S license
* LICENSES\ - contains all project licenses
